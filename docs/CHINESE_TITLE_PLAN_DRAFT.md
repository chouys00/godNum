## 1. 目標與範圍

輸入 nhentai 作品頁連結或既有六位數，解析該頁的文字中繼資料，穩定辨識有證據支持的中文作品名稱；作者名稱若存在，一併記錄，並保留來源網址與欄位證據。

本草案的範圍假設：中文名稱取自目前作品頁提供的標題資料，不進行其他作品頁、中文版本或閱讀／下載來源的搜尋。若使用者要求原頁沒有中文名稱時仍必須取得名稱，這份草案不能保證滿足，須在審閱時另行確定名稱來源。

中文名稱的意思是「來源標示或有充分證據支持的中文標題」，不宣稱官方譯名，也不表示作品有官方中文版。第一版保留繁簡原文，不自動互轉或翻譯。僅處理非露骨的書目文字，不處理作品圖片、內文、封面辨識或閱讀／下載入口。

## 2. 現況與可重用部分

本次依工作區實際程式檢查：

- `src/core/lookup.js`：六位數驗證與精確來源網址驗證；目前不接受完整連結作為輸入。
- `src/content/source-extractors.js`：API／結構化資料與 DOM 的標題、作者和社團解析；尚未保留語言資訊。
- `src/adapters/source/source-adapter.js`：逐欄 fallback、長度限制、證據與 record validator；目前只有日文、英文、顯示標題，沒有中文名稱解析結果。
- `docs/SOURCE_SCHEMA.md`：record schema 為 1；新增欄位須連同精確欄位驗證更新。
- `src/core/state.js`、訊息驗證、背景程式與側邊面板可重用，但須檢查新增 schema 的相容性。
- `manifest.json` 目前仍包含 DLsite 權限與 content script；縮小範圍後需一併處理執行中的 DLsite 依賴。
- 現有 F1 是 DLsite 驗收，控制狀態為 FAIL；此失敗不代表新的中文名稱解析方案已驗證或不可行。

既有程式可重用程度不等於新版需求通過；本輪僅閱讀程式，未重新執行測試或實站解析。

## 3. 輸入與輸出

輸入支援六位半形數字，以及精確 HTTPS 來源網域的 `/g/<六位數>/` 作品連結。可接受缺少尾斜線並正規化；拒絕帳密、非核准網域、其他路徑、query 與 fragment。不要在本次順便擴充其他號碼長度或網站。

輸出保留原始標題變體，另增加下列邏輯欄位；實際 schema 在 M1 凍結後確定：

| 欄位 | 用途 |
|---|---|
| `number`、`sourceUrl` | 識別目前輸入與資料來源 |
| 既有原始標題欄位 | 保留來源文字，不因中文解析覆寫 |
| `languageEvidence` | 頁面明示的語言訊號及 locator；未知則空 |
| `chineseTitle` | 確認的中文名稱或 null |
| `chineseTitleStatus` | `confirmed`、`ambiguous`、`not_available` |
| `chineseTitleCandidates` | 有界的待確認標題片段，附不確定原因 |
| `authors`、`groups` | 作者與社團分開存放；缺少時為空陣列 |
| `evidence`、`ruleVersion` | 原欄位路徑、原文片段、採用規則及版本 |

來源存取結果沿用獨立的 `success`、`manual_action`、`not_found`、`error`。只有成功取得來源資料後才給中文名稱判定；網站受阻不能寫成「沒有中文名稱」。

`not_available` 僅表示「本頁可用資料中沒有可確認的中文名稱」，不能寫成「作品沒有中文名稱／中文版」。

## 4. 中文名稱判定原則

1. 先取得原始標題與實際存在的語言證據；不得假設網站提供 `title.chinese` 或其他尚未觀察到的欄位。
2. 欄位名稱是 `english`、`japanese` 或 `pretty`，不代表其中每段文字的實際語言。保留欄位來源，另行判定文字片段。
3. 只解析標題區與允許的結構化欄位，不從介紹、評論、標籤列表或頁面全文猜測名稱。
4. 不以漢字存在、沒有假名、繁體字特徵或作品語言標籤單獨確認中文標題；純漢字中日文歧義必須保留待確認。
5. 頁面明示 Chinese 只支持作品語言，不能證明某一標題片段為中文。確認需有標題本身的語言證據或經實測、固定規則可辨識的明確語言標註關係。
6. 混合標題、分隔符、括號與附註的解析規則只在取得真實格式證據後加入。不得任意刪除所有括號；括號可能是作品名稱的一部分。
7. 中文名稱原文、清理後顯示值與來源片段可追溯。只可依明確規則移除確定是作者／社團前綴、語言或翻譯附註的文字。
8. 多個互相衝突的中文片段不得任選；回報 `ambiguous`。低優先序標題資訊若提供不同中文片段，也須保留供判定，不可因原欄位 fallback 已成功就遺失。
9. 作者優先使用明示 artist／author 資料；社團不當作者，翻譯者不當原作者。第一版不從任意括號推測作者，也不將羅馬字作者翻成中文。

若這些保守規則在代表案例中無法取得足夠中文名稱，M1 應提出範圍不成立的結論。不可用大量 `not_available` 或降低確認標準，冒充「穩定找到中文名稱」。

### M0：核准後同步正式計畫

- 對照本草案、使用者審閱意見與當下工作區，不直接沿用前一轮未完成的多平台改寫。
- 同步 `PROJECT_SPEC.md`、`PROJECT_ROADMAP.md`、`DECISIONS.md`、`NEXT_TASK_HANDOFF.md`、`DEVELOPMENT_STATUS.md`、驗收及補驗文件。
- 控制狀態僅在 `STAGE_STATE.yaml` 更新；新增 M0 → M1 → M2 → M3 → A6 順序，保留既有階段歷史。
- 舊 DLsite F1／A3 至 A5 標示為被新範圍取代，不把其 pending／FAIL 改寫成 passed 或 waived；A6 最終人工驗收仍保留。
- 保持既有需求 ID 含義；新增需求採新 ID，避免其他文件的交叉引用失效。
- 完成條件：文件一致、範圍明確、A6 未被取消。

### M1：先驗證中文名稱資訊是否存在（阻擋閘門）

- 僅檢查作品頁的非露骨文字中繼資料；工具不可存取時，使用者可提供去識別化的標題與語言欄位樣本。不得繞過網站限制或改找內容副本。
- 先建立至少 12 筆互不重複、非只挑成功案例的來源中繼資料樣本，涵蓋中文標題、混合語言、纯漢字歧義、日英標題、缺作者與資料衝突。
- 至少 5 筆具有人工可確認的中文名稱，至少 3 筆無中文名稱或有語言歧義；不足時報告樣本缺口，不捏造實站正例。
- 逐筆人工標註中文名稱、作者、證據及可判定原因；未知保持未知。用虛構文字重建同格式 fixture，不保存真實作品全文。
- 凍結規則、資料契約與驗收表，並在後續 M3 使用新的保留樣本驗證。
- 分別報告有中文名稱比例、可正確解析比例與無法判定比例。
- 完成條件：有足夠真實格式證據證明此方法可取得中文名稱；提交使用者核對適用範圍與取得率後才進 M2。頁面原本缺中文的案例須明确保留在報告分母，不能悄悄排除。

### M2：解析核心與契約實作

- 擴充來源 extractor 以保留 M1 證實存在的語言與必要標題證據。
- 新增純函式中文標題解析模組；不依賴 DOM、網路、AI 或遠端翻譯。
- 更新 source record／snapshot schema、跨 context 訊息驗證、長度限制與 storage 相容性；schema 升版後舊資料依既有保守策略重設。
- 實作連結輸入正規化，沿用精確網域與號碼驗證。
- 必測：純漢字歧義、假名與漢字混合、中文片段、繁簡文字、合法括號、語言附註、衝突、缺作者、社團與翻譯者、惡意 HTML、超長字串、未知 schema、重複解析一致性。
- 完成條件：規則測試與既有相關回歸通過；每個確認值都可追溯至輸入資料。

### M3：側邊面板與保存整合

- 面板顯示中文名稱或明確狀態、作者、社團、原始標題及證據。避免把待確認候選當作主名稱。
- 連結／號碼輸入、人工重試、重新開啟面板、查詢切換、清除紀錄都須保持正確作品身分。
- 保存僅含有界中繼資料；沿用既有診斷隱私原則，診斷不自動加入標題／作者全文。
- 移除執行中的 DLsite 搜尋入口、content script 與無需保留的權限，同步調整 manifest 檢查；原型與歷史測試先保留，無需大規模刪除。
- 使用至少 5 筆未參與規則制定的新樣本驗證，涵蓋至少 2 筆中文正例與 2 筆歧義／缺中文案例；不足則補驗 pending。
- 執行 `npm run quality`，必要時以 `node test/run-tests.mjs` 定位失敗；測試通過後不重複無關檢查。
- 完成條件：離線整合通過，保留樣本結果與失敗原因有紀錄；不得以合成資料宣稱實站通過。

### A6：人工整體驗收

- 使用者在正常 Chrome 驗證輸入、擷取、中文名稱判定、作者、人工接手、狀態恢復與清除。
- 每筆已確認中文名稱與作者皆須對得上來源；有一筆錯誤確認就修正並回歸相關案例。
- 所有受工具限制的項目記入 `SUPPLEMENTAL_VALIDATION.md`，補驗完成前不得標記最終 accepted。
- 完成條件：新版 blocking 驗收通過，使用者接受實測中文名稱取得範圍，A6 方可 accepted／PASS。

## 6. 驗收指標與停止條件

| 指標 | 定義與用途 |
|---|---|
| 擷取正確性 | 成功讀取的標題與作者逐欄對照；全部有證據，禁止將缺值補猜 |
| 確認精確率 | 正確確認數／全部確認數；小樣本驗收要求零已知錯認，報告分子分母，不宣稱統計保證 |
| 中文名称解析召回率 | 正確確認數／人工證實本頁含中文名稱數；M1 建議暫定至少 80%，由使用者核准後採用 |
| 整體取得率 | 正確確認數／全部唯一樣本數；另列不可存取與未知真值，不能用「未找到」算成功 |
| 作者正確性 | 有明示作者時正確記錄；缺少時空值，多作者不丟失，社團不混入 |
| 可重現性 | 相同中繼資料與規則版本，中文結果及作者列表相同 |

沒有確認結果時精確率為 N/A；缺少中文正例時召回率為 N/A，不能算通過。若正例不足、純漢字歧義無法解決、或來源幾乎不提供中文名稱，停在 M1 提供實際數據讓使用者決定；不擴張成其他資源搜尋。
